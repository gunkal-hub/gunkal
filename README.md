# 뉴건즈 홈페이지로 올리기

이 폴더를 그대로 인터넷에 올리면 누구나 주소만으로 들어와서 할 수 있어요.
로그인·랭킹·친구 대전은 **Firebase**(구글 무료 서버)에 연결해야 켜져요. 연결하기 전에도 CPU 대전과 연습모드는 돼요.

준비물: 구글 계정, GitHub 계정(무료). 처음 하면 30분쯤 걸려요.

## 폴더 안 파일

| 파일 | 하는 일 |
|---|---|
| `index.html` | 게임 본체 |
| `web.js` | 로그인, 아이디·비번 찾기, 기록, 랭킹, 온라인 방 |
| `fb.js` | Firebase 프로그램을 불러옴 (안 건드려도 됨) |
| `config.js` | **내 Firebase 주소를 넣는 곳** (2단계) |
| `firestore.rules`, `database.rules.json` | 서버 보안 규칙 (1단계에서 붙여 넣기) |

## 1단계 · Firebase 프로젝트 만들기

1. https://console.firebase.google.com 에 들어가 **프로젝트 추가** → 이름 `newgunz` → 애널리틱스는 꺼도 돼요.
2. 왼쪽 **빌드 → Authentication → 시작하기 → 로그인 방법**에서 두 개를 켜요.
   - **이메일/비밀번호** (사용 설정, "이메일 링크"는 끔)
   - **익명** (비회원이 친구 대전에 들어올 때 씀)
3. **빌드 → Firestore Database → 데이터베이스 만들기** → 위치 `asia-northeast3 (서울)` → 프로덕션 모드.
   만든 뒤 **규칙** 탭에 `firestore.rules` 내용을 통째로 붙여 넣고 **게시**.
4. **빌드 → Realtime Database → 데이터베이스 만들기** → 위치 아무 데나(싱가포르가 가까움) → 잠금 모드.
   **규칙** 탭에 `database.rules.json` 내용을 붙여 넣고 **게시**.
   화면 위쪽의 주소(`https://...firebasedatabase.app`)를 복사해 둬요.

## 2단계 · config.js 채우기

1. Firebase 왼쪽 위 톱니바퀴 → **프로젝트 설정** → 아래쪽 **내 앱**에서 웹 아이콘(`</>`) 클릭 → 앱 이름 아무거나 → 등록.
2. 나오는 `firebaseConfig = { ... }` 안의 값들을 `config.js`에 그대로 옮겨 적어요.
3. `databaseURL`에는 1단계 4번에서 복사한 주소를 넣어요.

> config.js 값은 공개돼도 괜찮은 값이에요. 보안은 1단계의 규칙이 맡아요.

## 3단계 · GitHub Pages로 올리기 (무료 홈페이지)

1. https://github.com 에서 **New repository** → 이름 `newgunz` → Public → Create.
2. **Add file → Upload files**로 이 폴더의 파일을 전부 끌어다 놓고 **Commit changes**.
3. 저장소의 **Settings → Pages** → Source: `Deploy from a branch`, Branch: `main` / `(root)` → Save.
4. 1~2분 뒤 `https://내아이디.github.io/newgunz/` 가 내 홈페이지 주소예요. 이 주소를 친구에게 알려 주면 돼요.

## 4단계 · Firebase에 내 주소 알려 주기

1. **Authentication → 설정 → 승인된 도메인**에 `내아이디.github.io` 추가.
2. **Authentication → 템플릿 → 비밀번호 재설정**
   - 연필 아이콘 → 아래 **작업 URL 맞춤설정** → `https://내아이디.github.io/newgunz/` 입력 → 저장.
   - 이렇게 해야 메일 속 링크를 눌렀을 때 우리 게임 화면에서 **아이디를 보여 주고** 새 비밀번호를 정해요.
     안 하면 구글 기본 화면에서 비밀번호만 바뀌고 아이디는 안 보여요.
   - 제목을 `뉴건즈 아이디·비밀번호 찾기`처럼 바꿔 두면 친구들이 덜 헷갈려요. 템플릿 언어도 한국어로 바꿀 수 있어요.

## 이렇게 동작해요

- **회원가입**: 아이디(영어 소문자·숫자·밑줄 3~16자) + 비밀번호(6자 이상) + 이메일. 인증 메일은 안 가요.
- **로그인**: 아이디 또는 이메일 + 비밀번호.
- **아이디·비번 찾기**: 이메일을 넣으면 메일이 가요 → 링크를 누르면 게임 화면에서 아이디 확인 + 새 비밀번호 설정.
- **비회원**: 로그인 없이 모든 모드 가능. 친구 대전에도 들어올 수 있지만 기록·점수는 안 남아요.
- **기록**: 친구 대전에서 K.O.는 킬, 당한 K.O.는 데스. 2선승 한 판이 끝나면 승/패, 킬뎃, 최근 전적이 저장돼요.
- **계급**: 아이언 IV에서 시작 → 아이언·브론즈·실버·골드·플래티넘·에메랄드·다이아몬드(각 IV→I) → 마스터 → 그랜드마스터 → 챌린저.
  100점이면 한 단계 승급, 0점 밑으로 떨어지면 한 단계 강등. **회원끼리 붙은 판만** 점수가 움직여요.
- **점수(철권식)**: 기본 이기면 +30, 지면 −24.
  - 예상대로 끝난 판(높은 계급이 이김): 계급 차이가 클수록 적게 얻고 적게 잃음 (1티어 차이 +20/−16, 2티어 +9/−7).
  - 낮은 계급이 이긴 이변: 차이가 클수록 크게 움직임 (1티어 차이 +45/−36, 2티어 이상 +60/−48).
  - 숫자는 `web.js`의 `rankDelta`에서 바꿀 수 있어요.

## 알아 둘 점

- **무료 한도**: Realtime Database는 월 10GB 내려받기가 무료예요. 대전 1시간에 한 사람당 약 100MB라서, 친구끼리 한 달 수십 시간은 무료로 충분해요. 동시 접속은 100명까지예요.
- **조작 방지 한계**: 서버 없이 각자 브라우저가 결과를 저장하는 방식이라, 마음먹고 브라우저 개발자 도구를 만지는 사람은 점수를 조작할 수 있어요. 친구끼리 즐기는 용도로는 괜찮지만, 모르는 사람이 많이 오는 공개 랭킹이 되면 Cloud Functions(유료 요금제)로 서버 판정을 붙여야 해요.
- **이메일 노출**: 아이디로 로그인하려면 아이디 → 이메일을 찾아야 해서, 남의 아이디를 아는 사람은 그 이메일을 알아낼 수 있어요. 싫다면 이메일 로그인만 쓰도록 바꿀 수 있어요.
- **반응 속도**: 각자 자기 화면에서 맞았는지·막았는지 판정해요. 지연이 있으면 공격한 쪽은 타격이 아주 살짝 늦게 보여요.
